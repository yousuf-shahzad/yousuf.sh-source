What changed beneath the surface

  • Removed the artificial introduction delay, custom cursor, scrolling overrides, and WebGL dependency.
  • Added reusable layouts, project previews, links, contact callouts, and a single metadata source.
  • Published Markdown is validated and safely rendered during the build; drafts are excluded.
  • Every public route has static HTML, with generated sharing metadata and a sitemap.
  • Content and generated-page regression tests are part of CI.
  • Project illustrations communicate themes; they are not product screenshots. Existing project claims are preserved without invented metrics or dates.
